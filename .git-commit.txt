feat(eval): add reporting tool for CSV summaries and comparisons

- Add scripts/report_eval.py
  - Summarizes overall accuracy and per-subject/level metrics for one or more CSVs
  - Compares two CSVs head-to-head (delta counts, per-level/subject deltas, example diffs)
  - Optional JSON/Markdown export for dashboards
- Update llm.state with addition and usage notes

Usage examples
- Summarize both CSVs:
  python scripts/report_eval.py \
    --csv outputs/eval/math500_merged_chat.csv outputs/eval/math500_adapter_chat.csv
- Compare adapter vs merged:
  python scripts/report_eval.py \
    --compare outputs/eval/math500_merged_chat.csv outputs/eval/math500_adapter_chat.csv \
    --out_json outputs/eval/report_math500.json --out_md outputs/eval/report_math500.md
